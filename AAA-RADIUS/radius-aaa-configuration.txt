AAA and RADIUS Configuration
============================

Device: NAC-SW1


AAA GLOBAL CONFIGURATION
------------------------

aaa new-model

aaa authentication dot1x default group radius

aaa authentication login RADIUS_AUTH group radius local

SSH AUTHENTICATION

LOCAL USER FALLBACK
-------------------

username admin
username admin-local

Local authentication is available as a fallback when the
RADIUS authentication server is unavailable.
